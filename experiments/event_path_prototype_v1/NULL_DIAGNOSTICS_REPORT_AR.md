# تقرير Null Diagnostics v1

## العقد

أُجريت ثلاثة اختبارات فقط، كل منها بـ1,000 تكرار وبالبذرة `20260828`. لم تُفتح عائلة Null إضافية.

| Null | ما الذي يكسره؟ | المتوسط العشوائي | p تجريبي |
|---|---|---:|---:|
| `break_event_outcome_association` | علاقة الحدث بالنتيجة مع إبقاء التنبؤات ثابتة | 0.5094 | 0.0190 |
| `break_temporal_order` | الترتيب الزمني داخل كل كيان مع إبقاء توزيعات النتائج | 0.5137 | 0.0789 |
| `break_path_identity` | هوية المسار داخل كل كيان مع إبقاء توزيع مخرجات النموذج | 0.5140 | 0.0529 |

الدقة المرصودة لـEvent-Path هي `0.5274` على 3,229 تنبؤًا OOS.

## الحكم

الاختبار الأول يجيب بوضوح أن التفوق لا يختفي تمامًا عند كسر علاقة الحدث بالنتيجة؛ الفارق عن Null موجود، وp التجريبي 0.019. لكن الاختبارين الثاني والثالث لا يقدمان فصلًا حاسمًا عند عتبة 0.05: الترتيب الزمني وهوية المسار يظهران إشارتين حدوديتين فقط (`0.0789` و`0.0529`). لذلك لا يصح تثبيت ادعاء قوي بأن التفوق يعتمد بوضوح على الزمن أو على هوية Path وحدها.

القرار المرحلي المجمّد هو: **Event-Path provisional / diagnostic support only**. لا يُرقّى إلى Edge تنبؤية مستقرة، ولا يُعدّل تعريفه، ولا تفتح Nulls جديدة. يمكن إجراء Seismic Transfer Test استكشافي بالعقد المجمد نفسه، لكن نتيجته لا تعود لتعديل النموذج الاقتصادي أو تغيير الحكم السابق.
