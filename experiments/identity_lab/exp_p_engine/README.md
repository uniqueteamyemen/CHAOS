# exp_p_engine — المحرك الموحّد

> **آخر تحديث: 2026-11-14 (+03:00)**

## ما هو

خط أنابيب واحد يجمع كل ما بُني وبقي صالحاً:

```
بُقيا الهوية
  → خط أساس: انحياز مجمّد (إزاحة الهوية) + σ متحرك (مقياس الضجيج)
  → كواشف: sign-run (P1) و CUSUM (P2)
  → عدّاد: C (عدد الكسور) و M (متوسط المقدار) (P3)
  → مدير إنذارات: أولوية، كتم P1 محصور بالكيان، تهدئة، تصفير بتأكيد المشغّل
```

## القرارات المبنية (ولماذا)

| القرار | السبب |
|---|---|
| **انحياز مجمّد + σ متحرك** | نافذة متحركة للانحياز **تبتلع** أي تسرب مستمر (تصبح البُقيا صفراً بعد نافذة). الانحياز إزاحة هوية تُجمّد وتُرقّم؛ σ وحدها تتحرك لأن الضجيج يتغير فعلاً. |
| **لا STL** | F=1.21 على بُقيا EIA → الموسمية تتساقط جبرياً في طرح طرفي الهوية. |
| **CUSUM معتمد** | يغلق فجوة التسربات الصغيرة (1–4) التي يفوّتها sign-run، عند ميزانية إنذار كاذب 5%. |
| **العدّاد بدل كاشف بنية** | النبض = تقلب C، وتغيّر المعدّل = انزياح M. تصميم واحد بدل كاشفين. |
| **كتم P1 محصور بالكيان** | كتم شامل يخفي تسرباً ثانياً مستقلاً. |
| **تصفير CUSUM بتأكيد المشغّل** | تصفير تلقائي يخفي تسرباً مستمراً. |

## الاختبارات (9/9)

- بلا تسرب → صامت.
- تسرب ثابت → P1.
- تسرب صغير (2/شهر) → P2 فقط (CUSUM).
- P1 يكتم P2 لنفس الكيان.
- التهدئة تمنع التكرار.
- تدفق نقدي → نفس السلوك (مجال ثانٍ).
- **الانحياز المجمّد لا يبتلع تسرباً مستمراً** (اختبار الانحدار الحرج).
- العدّاد يُبلّغ عن الكسور.
- خط الأساس يُبلّغ عن الانحياز والـσ.

## النطاق والحدود

- **يشمل**: هويات حفظ عددية (مخزون، تدفق نقدي).
- **لا يشمل**: هويات منطقية/عقدية (PayLock H1 — وحدة `exp_a` منفصلة).
- **حدود معلنة**: لا إسناد بلا تسجيل ثانٍ؛ لا كشف تحت حساسية CUSUM.
