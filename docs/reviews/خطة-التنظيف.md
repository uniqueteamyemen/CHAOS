## ما أحتاجه منك لبدء التنفيذ

قرارات محددة (سأوقّف عند كل واحدة):
1. هل أُجري **فحص الأسرار** الكامل أولاً؟ (اقترح نعم)
2. أي مستودع Pharma سيكون **المصدر الموحّد**؟
3. هل CHAOS2 يُحذف نهائياً أم يُؤرشف؟
4. هل أبدأ بتصحيحات البيانات الوصفية غير المؤذية (الأسماء/الوصف/README)؟

> **التزام:** أي تعديل — حتى تصحيح وصف — سيُعرض عليك كـ diff قبل تنفيذه، ولن أدفع (push) أي شيء دون أمرك.
