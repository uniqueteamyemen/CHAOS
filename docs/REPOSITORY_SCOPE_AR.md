# نطاق مستودع CHAOS

## القرار التنظيمي

أصبح `CHAOS` المستودع المستقل لحفظ وترتيب أعمال الطبقة التاريخية، كتالوجات البيانات، بوابات الجاهزية، عقود التجارب، وأدوات التحليل. لا يُستخدم هذا المستودع لاستبدال أو تعديل `market-intelligence-engine`؛ الريبو القديم يظل مشروعاً منفصلاً.

## ما دخل GitHub

تم حفظ الوثائق والتقارير العربية والإنجليزية، ملفات provenance وmetadata، أدوات الفهرسة والاستخراج، prototype المستقل، الرسوم، ملفات المقارنة، المصفوفة الخام الصغيرة الخاصة بـ`macro_plus_eia_energy`، وعقد التجربة بصيغتي Markdown وJSON.

## ما لم يدخل GitHub

لم تُرفع أرشيفات WDI وIMF وUCDP وEIA وNOAA وGDELT الخام، ولا الملفات staged الكبيرة، ولا `node_modules`. السبب مركب من حجم GitHub، قابلية إعادة البناء، وشروط إعادة توزيع البيانات الخارجية. بقيت هذه الأصول في `/home/ubuntu/market_intelligence_workspace/` مع تسجيل كل ملف ومساره وحجمه وSHA-256 في:

`manifests/EXTERNAL_ASSET_MANIFEST.csv`

هذا ليس حذفاً للبيانات. إنه فصل بين مستودع الكود/التوثيق وبين مخزن الأصول الخارجية. يمكن إعادة ربط الملفات محلياً أو عبر مخزن أرشيفي مصرح به لاحقاً.

## قاعدة البيانات العلمية

لا توجد في هذا المستودع عملية تطبيع أو تعبئة فجوات أو reconciliation قسري. القيم الخام تبقى مفصولة حسب المصدر. كما أن وجود Experimental Contract لا يعني أن TFT أو أي نموذج قد شُغّل؛ العقد مواصفة مراجعة مسبقة فقط.

## التحقق

قبل الدفع إلى GitHub يجب التأكد من عدم وجود ملف أكبر من 100 MB داخل النسخة المعدة للرفع، ومن أن مجلدات `raw` و`staged` و`node_modules` غير متتبعة، ومن أن المستودع الأصلي لم يُعدّل.
