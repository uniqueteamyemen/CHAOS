# CHAOS — نتائج الجولة الرسمية متعددة المصادر: UNCTAD

## UNCTAD Data Hub

المصدر الرسمي: https://unctadstat.unctad.org/EN/Index.html

توضح UNCTAD أن Data Hub يضم قواعد بيانات للتجارة والتنمية، وأن UNCTADstat Data Centre يجمع المؤشرات الإحصائية التي ينسقها الجهاز الإحصائي وفق قواعد مشتركة بهدف قابلية المقارنة بين مجموعات البيانات. يضم الكتالوج merchandise trade وservices trade والسلع الإبداعية والغذاء والحسابات القومية والاستثمار وميزان المدفوعات والتضخم وأسعار الصرف والسلع والنقل البحري والاتصال الملاحي، إضافة إلى التجارة المرتبطة بالبيئة.

## الدلالة البحثية

UNCTAD مرشح مستقل مهم لأنه لا يكرر فقط trade openness، بل يفتح متغيرات مرتبطة بالنقل والسلع والبيئة. مع ذلك، ظهور المجال في الكتالوج لا يساوي توفر ملف محدد جاهز للتحليل. يجب تثبيت dataset identifier، وحدات القياس، الفترة، التواتر، وطريقة التصدير من Data Centre قبل بناء ObservedRecords أو DomainStates.

## قرار الجولة

1. يُضاف UNCTAD إلى قائمة المصادر الرسمية المرشحة للمقارنة، وليس إلى Evidence Graph بعد.
2. الأولوية العملية هي merchandise/services trade السنوية ثم maritime/freight إذا أمكن تثبيت تعريفات وتغطية تاريخية.
3. لا تُمزج UNCTAD مع WDI أو WTO أو Comtrade ولا تُستخدم source averaging.
4. صفحة Data Centre التي لم تعرض عناصر نصية في المتصفح تُسجل كحالة `catalog_accessible_dataset_export_unconfirmed` إلى أن يُثبت ملف تنزيل أو API رسمي.
